Quota 0.6.1 · GPT 额度悬浮窗
Windows 10/11 x64 · 官方账号接口版

开始使用
1. 右键旧版小窗的托盘图标 → 退出。以前安装的“GPT 额度小窗”浏览器插件可以停用。
2. 把整个压缩包“全部解压”到固定文件夹。不要只取出 exe，也不要在压缩包内直接运行。
3. 双击 Quota.exe。engine 文件夹必须与 Quota.exe 放在一起。
4. 点“连接 ChatGPT”，在默认 Edge/Chrome 浏览器打开的官方页面完成授权，可使用 Apple 登录。
5. 授权成功后小窗会查询额度。之后可以关闭授权页，甚至关闭浏览器；不再需要插件或使用情况页。
   首次请将显示的百分比与网页使用情况核对一次，确认授权的是同一个账号和工作空间。

界面与贴边操作
默认窗口宽度缩小到 272 个逻辑像素。按住标题、数字或背景空白处拖动，按钮仍正常点击。
拖到屏幕左边或右边约 24 个逻辑像素范围内松开，即吸附并收起为 76×34 的数值条。
数值条只显示当前最紧张额度的剩余百分比。鼠标停留可看所属额度；未连接、暂停、断线或过期显示横线。
单击数值条展开详情，鼠标离开约 0.7 秒后自动收回。直接把数值条拖离边缘即可恢复自由悬浮窗。
右上角 ··· 现在打开独立深色按钮菜单；数值条上右键也可打开。
菜单包含：窗口置顶、精简模式、拖到边缘自动收起、收起到侧边、暂停/恢复同步、重新授权、说明、退出。
− 收进托盘；双击托盘图标恢复。右下角 ↻ 立即同步。
位置、置顶、精简、自动贴边设置会保存；重新启动会恢复贴边状态。
每分钟查询一次，低于或等于 20% 时提醒；断网/过期不会伪造新的额度。

授权与数据
额度来源：OpenAI 官方 Codex App Server，account/rateLimits/read。
监测范围是 ChatGPT Work / Codex 共用的套餐额度，不是所有普通聊天模型、图片或语音限制的全集。
官方组件负责浏览器 OAuth、保存和刷新授权。小窗不读取浏览器 Cookie，不需要 API Key，不提供密码输入框。
默认复用本机 Codex 的账号状态，授权状态也与本机 Codex 共用。若这台电脑已经登录 Codex，可能直接显示该账号额度；切换账号前注意核对。
小窗本身只调用初始化、账号读取、登录/取消登录、额度读取，不发起聊天、模型推理、文件执行、充值或重置额度。
本工具是个人使用的第三方工具，并非 OpenAI 官方出品。
窗口偏好保存在 %LOCALAPPDATA%\GPTQuotaNext。这里不会复制授权令牌。
官方组件的授权数据依照 Codex 自身配置保存，不要随意删除其他 Codex 数据。

常见问题
0.6.1 修复：优先按实际 Quota.exe 路径定位 engine，兼容单文件运行时目录。缺失时显示具体查找路径。
组件丢失/校验失败：重新完整解压原包，保留 engine 文件夹。不要自行替换里面的文件。
浏览器授权打不开：确保 Windows 默认浏览器已配置；检查网络后点击连接重试。
授权完成但没有读数：确认相同账号具有 Work / Codex 可读取的套餐额度，点 ↻ 重试。
系统提示未知发布者：本工具没有商业代码签名证书，无法提供签名发布者验证；请按自己的信任判断处理。

小窗源码在 source 文件夹，使用 .NET 8 SDK 构建：
dotnet publish source/Quota.csproj -c Release -r win-x64 --self-contained true
将 engine 文件夹复制到构建输出目录。首次启动会校验随包官方组件的 SHA-256。
